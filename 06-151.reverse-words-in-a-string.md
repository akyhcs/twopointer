
The key is to use the two pointers to **identify each word**, rather than trying to reverse the whole string first.

### Think about this

For:

```text
"the sky is blue"
```

Start from the right:

```text
the sky is blue
            R
            L
```

We use:

* `right` → finds the **end of a word**
* `left` → moves backward to find the **start of that word**

So:

```text
the sky is blue
         L   R
```

We found `"blue"`.

Then:

```text
the sky is blue
      L   R
```

We find `"is"`.

Then `"sky"` and `"the"`.

### Two-pointer solution

```java
public String reverseWords(String s) {

    StringBuilder result = new StringBuilder();

    int right = s.length() - 1;

    while (right >= 0) {

        // Skip spaces
        while (right >= 0 && s.charAt(right) == ' ') {
            right--;
        }

        if (right < 0) {
            break;
        }

        // right is at the end of a word
        int left = right;

        // Move left to the beginning of the word
        while (left >= 0 && s.charAt(left) != ' ') {
            left--;
        }

        // Add the word
        if (result.length() > 0) {
            result.append(" ");
        }

        result.append(s.substring(left + 1, right + 1));

        // Move to the previous word
        right = left - 1;
    }

    return result.toString();
}
```

### Let's understand the pointers

For:

```text
"the sky is blue"
```

Initially:

```text
right = 15
```

`right` moves over spaces if necessary.

Then:

```text
left = right
```

Now move `left` backwards:

```text
b l u e
^     ^
L     R
```

When `left` reaches the space:

```text
the sky is blue
        ↑
       left
```

we know:

```java
s.substring(left + 1, right + 1)
```

gives:

```text
blue
```

Then:

```java
right = left - 1;
```

Now we're positioned before `"blue"` and can find `"is"`.

---

### One important distinction

This is **two-pointer**, but it's not the same type of two-pointer pattern as:

```text
left → 
        <--- search --->
                    ← right
```

from problems like **Two Sum**, **3Sum**, or **Container With Most Water**.

Here the two pointers are being used as **boundaries of a word**:

```text
left                  right
 ↓                       ↓
[t][h][e] [s][k][y] [i][s] [b][l][u][e]
```

So the pattern to recognize is:

> **One pointer finds the boundary/end, and the second pointer scans backward to find the other boundary.**

That's a useful two-pointer pattern to add to your DSA toolkit.

## The most important part to understand

Don't try to memorize the code.

Understand these **3 movements**:

### 1. `right` finds the end of a word

```java
int right = s.length() - 1;
```

Then:

```java
right = left - 1;
```

moves us toward the previous word.

---

### 2. `left` finds the beginning of the word

```java
int left = right;

while (left >= 0 && s.charAt(left) != ' ') {
    left--;
}
```

So we have:

```text
        word
         ↓
the sky [blue]
         ↑   ↑
        left right
```

Actually, after the loop:

```text
the sky [blue]
        ↑     ↑
       left  right
```

where `left` is sitting on the **space before the word**.

---

### 3. `substring()` extracts the word

Because `left` is on the space:

```java
s.substring(left + 1, right + 1)
```

For `"blue"`:

```text
index:   10 11 12 13 14
         ↑  b  l  u  e
         L           R
```

So:

```java
substring(11, 15)
```

gives:

```text
"blue"
```

---

### The mental model I'd use in an interview

Don't think:

> "I need to reverse the string."

Think:

> **"I will start from the right, find one complete word using two pointers, append that word, then jump to the previous word."**

That's the entire algorithm.

```text
        RIGHT
          ↓
the sky is blue
            ↓
          "blue"
             ↓
          result

the sky is
       ↓
      "is"
       ↓
    result

the sky

  "sky"
   ↓
 result

the

"the"
 ↓

```

Result:

```text

```

This is the part you should be able to explain without looking at the code.
