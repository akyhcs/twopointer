You're **very close**. In fact, you got **2 out of the 3 cases exactly right**.

Your code:

```java
while (mid <= high) {

    if (nums[mid] == 0) {
        swap(nums, l, mid);

        mid++;
    }
    else if (nums[mid] == 1) {
```

The only mistake is here:

```java
r--;
mid++;   // ❌
```

For `2`, **do not increment `mid`**.

---

## Why?

Let's create a case where your code fails:

```text
[1, 2, 0, 1]
```

Initially:

```text
l = 0
mid = 0
r = 3
```

```text
[1, 2, 0, 1]
 ↑
mid
```

### `nums[mid] == 1`

So:

```java
mid++;
```

Now:

```text
[1, 2, 0, 1]
    ↑
   mid
```

### `nums[mid] == 2`

We want to move this `2` to the right.

Swap `mid` and `r`:

```text
[1, 1, 0, 2]
    ↑     ↑
   mid   r
```

Then:

```java
r--;
```

So:

```text
[1, 1, 0, 2]
    ↑   ↑
   mid  r
```

Now look carefully.

**What is sitting at `mid`?**

```text
[1, 1, 0, 2]
       ↑
      mid
```

It's a **0**.

We haven't processed that `0` yet!

But your code says:

```java
mid++;
```

So you skip over the `0`.

Now:

```text
[1, 1, 0, 2]
          ↑
         mid
```

Loop ends.

And the array is:

```text
[1, 1, 0, 2]
```

❌ Not sorted.

---

# Therefore

For:

```java
else { // nums[mid] == 2
    swap(nums, r, mid);
    r--;
}
```

**Do not move `mid`.**

Because after the swap:

```text
        mid
         ↓
[ 0s | 1s | ? | 2s ]
             ↑
          unknown
```

The element that came from the right side is **unknown**.

We need to inspect it again.

---

### Your three rules are therefore:

```java
if (nums[mid] == 0) {
    swap(nums, l, mid);
    l++;
    mid++;
}
```

Because we know we've correctly handled the `0`.

```java
else if (nums[mid] == 1) {
    mid++;
}
```

Because `1` is already in the correct middle region.

```java
else { // nums[mid] == 2
    swap(nums, r, mid);
    r--;
    // DON'T increment mid
}
```

Because the new `nums[mid]` is **not yet classified**.

### This is the core insight:

> **When you swap `2` with `high`, you know the `2` is handled, but you don't know what you just brought into `mid`.**

That's why `mid` stays.

And honestly, **this is exactly the part I would want you to discover rather than memorize**. Your original code was a very reasonable first attempt.
